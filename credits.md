## Tools & Technologies Used

### Core Technologies
- **Python** — Primary programming language for data processing and AI modeling
- **TensorFlow / PyTorch** — Deep learning frameworks for AI model development
- **Scikit-learn** — Machine learning algorithms and data preprocessing
- **Pandas & NumPy** — Data manipulation and numerical computations

### Wind Farm & Energy Tools
- **OpenWake** — Wake effect modeling for wind turbine interactions
- **FLORIS** — Wind farm layout optimization framework (NREL)
- **WindPy / ERA5** — Wind data retrieval and meteorological analysis

### Visualization & Monitoring
- **Matplotlib / Seaborn** — Data visualization and performance charts
- **Plotly / Dash** — Interactive dashboards for real-time monitoring
- **Grafana** — Wind farm performance monitoring

### Infrastructure
- **Docker** — Containerization and deployment
- **GitHub Actions** — CI/CD pipeline
- **Jupyter Notebooks** — Experimentation and prototyping
